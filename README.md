# PopTracker Pack for Civ 5 by Sparky5000

This is a pack for PopTracker (Powerful Open Progress Tracker) which is available here https://github.com/black-sliver/PopTracker check the "Releases" section (right side of page) for the latest version and make sure you pick the right download option for your OS. Be sure to read the README provided for more info

this pack is meant to track your techs and policies retrieved as well as available building checks while playing Civ 5 AP currently being updated and maintained by 1313e

## Installation

Just download the pack and put in your poptracker/packs folder.
